## Nettverk

Et datanettverk er flere enheter som er koblet sammen slik at de kan kommunisere og dele informasjon.

En IP-adresse brukes til å identifisere en enhet på et nettverk.

En standard gateway er vanligvis ruteren som brukes når enheten skal kommunisere med andre nettverk, for eksempel Internett.

Ping kan brukes til å teste om en annen enhet eller adresse kan nås over nettverket.
